# Улучшение точности и внешнего вида — поэтапно

Выбор пользователя: улучшать и работу мозга, и внешний вид.

## Выполненный этап: анатомия выбранных нейронов и подробная динамика

### Геометрия

В 3D-окно добавлены 20 настоящих SWC-реконструкций из MaleCNS v1.0: GF/DNp01,
LC4, LPLC2, DNa01, DNg07, ORN_DM1, ORN_DA1 и MN9. Всего 55 854 отрезка.
Они используют тот же масштаб и систему координат, что и облако soma.
Это отростки конкретных клеток, не декоративные соединения между точками.
По частоте нейрона подсвечивается вся его реконструкция: распространение
импульса вдоль отдельных ветвей здесь ещё не рассчитывается.

Исходные SWC, URL и SHA-256 сохранены в `data/morphology/` и
`terrarium/data/neuron_arbors.json`. При отсутствии координат soma отростки
выбранного нейрона всё равно могут отображаться: это другой файл геометрии.
[Официальные морфологические данные MaleCNS](https://male-cns.janelia.org/download/).

### Подробный режим расчёта

Переключатель находится в правой панели окна **B**. Смена режима создаёт новый
мозг с начальным состоянием. Режим `research` адаптирует токовую LIF-модель
[Shiu et al., Nature 2024](https://doi.org/10.1038/s41586-024-07763-9) и
[авторский код](https://github.com/philshiu/Drosophila_brain_model).

| Параметр | Подробный режим |
| --- | --- |
| Шаг | 0.2 мс |
| Потенциал покоя / сброса | −52 мВ |
| Порог | −45 мВ |
| Время мембраны | 20 мс |
| Затухание синаптического тока | 5 мс |
| Задержка передачи | 1.8 мс |
| Восстановление после импульса | 2.2 мс для обычных клеток |
| Внешние входы | Прибавка 68.75 мВ в моменты случайных сенсорных событий |
| Синаптический вес | 0.275 мВ × число синапсов × знак/коэффициент медиатора |

Решение линейных уравнений на шаге аналитическое. Во время восстановления
переменные клетки зафиксированы и новые входы блокируются; активно
стимулируемые клетки, как в исходной процедуре PoissonInput, имеют нулевой
интервал восстановления. У подробного режима нет фонового принудительного
спайкинга всех нейронов, `log1p` весов, нормировки входов или искусственной
глобальной стабилизации из быстрого режима.

**Что подтверждено:** три независимых сравнения с Brian2 2.9 проверяют
напряжение, ток, задержки, восстановление и точное совпадение времён импульсов
на небольшой направленной сети с возбуждением и торможением, при шагах 0.2
и 0.1 мс, включая сенсорные события. Допуск по напряжению/току — 0.0002 мВ.
Это проверка вычисления данных уравнений, не подтверждение поведения живой мухи.

В эксперименте на полном выбранном графе GF дал 0 импульсов без стимула,
689 при сильном приближении и 0 после блокировки его входов. Два события
побега появились только при доступном входе GF. Исходный эксперимент:
`data/research_benchmark.json`. Большая частота сама по себе не означает
более реалистичную реакцию — это ещё требует экспериментальных ориентиров.

**Производительность:** в отдельном CPU-тесте две секунды времени модели
занимали около 4.7–6.5 секунды до учёта интерфейса. Окно показывает измеренный
множитель времени; тело и длительность воздействий замедляются вместе с мозгом.
В полной проверке с интерфейсом был зафиксирован множитель около **0.15×**
(примерно 6–7 секунд реального времени на секунду модели).
Прежний режим с шагом 2 мс остаётся для более быстрого наблюдения.

### Ограничения переноса

Исходная работа использовала FlyWire, а здесь остаётся более новый MaleCNS.
Это наша адаптация, не опубликованная и проверенная авторами модель MaleCNS.
Знаки/коэффициенты медиаторов, одинаковые параметры разных клеток, отсутствие
электрических синапсов, рецепторных различий и точной сенсорной трансдукции
остаются упрощениями. Многокомпартментная электрическая модель дендритов
не реализована. Ни подробная геометрия, ни меньший шаг этого не исправляют.

## Следующие этапы

1. **Зрение:** считать изменение изображения объекта относительно глаз мухи,
   отдельно проверять реакцию на рост углового размера и скорость; сравнить
   с опубликованными кривыми LC4/LPLC2/GF. Сейчас сигнал испуга задан фазой
   движения объекта. [Данные о цепи](https://doi.org/10.1016/j.cub.2019.01.079).
2. **Калибровка:** несколько начальных состояний и уровней воздействия,
   контрольные вмешательства, сравнение частот и задержек с экспериментом.
   Не подбирать параметры только ради красивой реакции в террариуме.
3. **Тело:** исследовать перенос физического тела и контроллеров из
   [flybody](https://github.com/TuragaLab/flybody). Сейчас положение тела,
   посадка, границы и анимация процедурные. Совместимость готовых контроллеров
   с Windows и скорость на RTX 4060 ещё не проверены.
4. **Isaac:** отдельный адаптер, затем обучение выходного контроллера с
   измеримой наградой. Улучшение анатомии не даёт игрового навыка автоматически.

## Повторить проверку

```powershell
.\.venv-reference\Scripts\python.exe -m pytest reference_tests -q --disable-warnings
.\.venv\Scripts\python.exe droffel_sim.py --profile research --gpu off --benchmark
```

Brian2 для эталонной проверки установлен отдельно с NumPy 1.26.4: Brian2 2.9
несовместим с NumPy 2.4 основного окружения, а Brian2 2.10 требует Python 3.12+.
Рабочий террариум использует свой NumPy/CuPy и не запускает Brian2 внутри цикла.
